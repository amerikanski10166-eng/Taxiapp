# Taxi KZ

Приложение для таксистов Казахстана.

## Первый этап
- Кабинет водителя
- Онлайн/оффлайн статус
- Доход и цель на день
- «Радар КЭФА»
- Список доступных заказов
- Бонусы за приглашение водителей
- Профиль и автомобиль
- Нижняя навигация

Название **Taxi KZ** временное — его можно заменить позже.
